# Block texture sources

`source/wood-side-revision.png` and `source/wood-top-revision.png` are the high-resolution sources for the current 128×128 wood block faces. The earlier flat SVG drafts were removed because they no longer matched the game assets.

`kiln_brick.png`, `kiln_vent.png`, and `kiln_lit.png` are original 32×32 masonry and vent art, generated deterministically by `python3 assets/textures/blocks/source/kiln.py` using only Python's standard library.
