# Block texture sources

The current terrain albedo textures (`grass_top`, `grass_side`, `dirt`, `stone`,
`sand`, `snow`, `moss`, `gravel`, and `glowstone`) are a local trial of the user's
NAPP 512x FREE 5.0.1 pack, provided from `Downloads/NAPP_512x_FREE_5.0.1`.
NAPP is by the NAPP team: https://napplab.com/.

`source/import_napp.py` imports the block PNGs at 128×128 with Lanczos filtering.
Grass uses a fixed green tint (RGB 145, 189, 89); its tinted alpha overlay is
composited over the supplied dirt side before resizing. Source `moss_block.png`
maps to our `moss.png`. Normal (`_n`) and specular (`_s`) companion maps are not
imported: the current material pipeline consumes albedo only.

To reproduce from the original local pack:

```sh
uv run --with pillow assets/textures/blocks/source/import_napp.py \
  /Users/hazel/Downloads/NAPP_512x_FREE_5.0.1/assets/minecraft/textures/block
```

The previous terrain PNGs remain available in Git before this import.

`chest_side.png` and `chest_top.png` are original wooden Chest art, generated by `python3 assets/textures/blocks/source/chest.py` using Python's standard library.

`hopper_side.png` and `hopper_top.png` are original metal/down-arrow and intake pixel art, generated by `python3 assets/textures/blocks/source/hopper.py` using Python's standard library.

`source/wood-side-revision.png` and `source/wood-top-revision.png` are the high-resolution sources for the current 128×128 wood block faces. The earlier flat SVG drafts were removed because they no longer matched the game assets.

`kiln_brick.png`, `kiln_vent.png`, and `kiln_lit.png` are original 32×32 masonry and vent art, generated deterministically by `python3 assets/textures/blocks/source/kiln.py` using only Python's standard library.
