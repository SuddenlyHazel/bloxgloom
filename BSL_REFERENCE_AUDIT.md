# BSL reference and enhanced rendering

The reference is the checked-in `external/shaders/lib/settings.glsl` default profile, as confirmed by the user. Equation-level checks use the actual GLSL source; there is no matched Minecraft/Iris runtime frame capture. Whole-frame BSL parity is therefore **not established**.

## Implemented source-equation matches

- `src/render/sky/bsl.wgsl` ports default `BSLTonemap` from `program/composite5.glsl`: exposure multiplier 4, symmetric desaturation matrix (0.96/0.94 diagonals, 0.03/0.01 off-diagonals), white curve 2, lower/upper curves 1, inverse saturation matrix, and final [0,1] clamp. The existing linear exposure control composes with that default multiplier. Default vignette strength 1.06 is applied before tone mapping. `BLOXGLOOM_BSL_STYLE=0` selects the previous display/sky styling.
- The same file ports default `GetSkyColor` from `lib/atmospherics/sky.glsl`: custom sky RGB 96/160/255, density day/night/weather 0.35/0.65/1.5, horizon curves 1/1.5, day/night exposure, sun/horizon mixing, squared night palette, rain gradient and ground attenuation. Light and ambient palettes come from the actual default settings and `lib/color/lightColor.glsl`; rain and day/night ambient mixing use its equations.
- `DrawStars` from `lib/atmospherics/clouds.glsl` supplies the default three-noise star mask, world-oriented projection, rain/moon visibility, moon-disc fade and phase-sensitive night palette. Engine presentation seconds supply the bounded frame-time input.
- `GetFogColor` from `lib/atmospherics/fog.glsl` now supplies directional clear/storm fog HDR color in the same source basis as the visible sky. This removes the legacy bright horizon calibration that became white under source tone exposure ×4; enhanced engine fog transmittance remains unchanged. Reference modes additionally port the source Overworld `NormalFog` defaults in `src/render/fog/reference.wgsl`: density 1, night multiplier 4, weather multiplier 1.5, indoor multiplier 1, optical dampening, height 62/falloff 128, and the source variable exponent. Default `FAR_VANILLA_FOG=2` excludes the Overworld, so reference mode does not apply the engine 38–135 m fade. Source `GetFogColor` minimum/exterior and bedrock attenuation are applied with explicit engine eye altitude, bedrock −64 and shelter input. Floating-origin LOD retains absolute eye altitude for the same fog-height equation.
- GPU regression tests compare tone output against an independent double-precision reference, and clear/rain sky against fixed source-equation goldens, and moon-phase night radiance against the squared phase multiplier. Reference air-fog fixtures use independent double-precision GLSL-default goldens for clear/night/rain/indoor/high-altitude extinction and exterior/bedrock color attenuation, and verify relative LOD altitude and scene-transport bypass. These verify the implemented functions, not a complete frame.

## Default materials versus enhanced materials

The checked-in profile comments out `ADVANCED_MATERIALS` and `ALBEDO_METAL`. Run with `BLOXGLOOM_BSL_REFERENCE=1` for the explicit default reference comparison: packed normals, material occlusion, POM, packed PBR, and path-traced GI are disabled. The source forward-lighting branch ports the default raw block-light curve, minimum light, vanilla face diffuse, smooth-lighting square, basic botanical SSS, albedo balancing, emission flattening, desaturation and rain/day/night palettes. Camera uniforms use source custom time warp and the −40° celestial orbit. This is an implemented material/lighting comparison, not whole-frame parity. Default operation retains enhanced rendering.

Run with `BLOXGLOOM_BSL_REFERENCE=advanced` for an explicitly **non-default** artistic-material comparison. It shares the reference orbit/palettes and disables path GI, while enabling packed material detail and BSL's advanced LabPBR remap. The production decoder sets artistic `GetMetalCol` base reflectance, source squared rational complex Fresnel and untinted reflection response (`ALBEDO_METAL` off), including reserved indices' source white fallback. Direct highlight Fresnel uses source `SphericalGaussianFresnel`. The artistic raster sky fallback and SSR subtraction call the same source-sky helper with matching sun/time/rain/moon inputs. Explicitly marked water keeps its separate optical fallback, preventing a second or mismatched subtraction. The actual fragment path preserves source metal lit-albedo treatment and its dielectric Fresnel/smoothness attenuation. The renderer still uses its existing microfacet highlight shape and screen-space reflection infrastructure: finite solar-disc GGX, BSL specular-color remapping, source normal damping, the complete advanced SSS shadow path, and the complete reflection/composite pipeline are not ported or validated as whole-frame equivalents.
The enhanced renderer preserves JG RTX/LabPBR decoding and material detail. Known conductor presets 230–237 now keep albedo tint over the **whole** reflected lobe: normal F0, grazing Fresnel, direct highlights, integrated environment response, reflection metadata and ray-traced sampling. Generic metal continues to use albedo F0 and a white Schlick grazing limit. Preset angular Fresnel now uses the exact unpolarized complex-Snell response rather than Schlick; generic-metal and dielectric paths retain their existing fast Schlick model. Preset direct highlights use height-correlated Smith GGX geometry. Integrated preset environment response uses 16 deterministic GGX visible-normal samples, applying exact angular Fresnel and the matching geometry/PDF ratio. It stays bounded by the material tint even at grazing. GPU angular goldens were independently evaluated with complex s/p reflection amplitudes, and constant-radiance GGX goldens use 16,384 reference samples. The 16-sample environment integral remains finite quadrature, not an exact closed-form BRDF integral.

The complex-Snell response and microfacet sampling follow the primary [PBRT conductor Fresnel](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission) and [GGX visible-normal/Smith model](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory) references.

Optional advanced BSL behaves differently: `GetMetalCol` uses artistic preset base-reflectance colors, while `ComplexFresnel` uses a simplified rational complex-index angular equation and then squares it. This differs from the enhanced exact complex-Snell response at oblique angles. With `ALBEDO_METAL` disabled it does not apply texture albedo tint. Named `bg_bsl_advanced_preset_base` and `bg_bsl_advanced_complex_fresnel` helpers are wired into the optional advanced runtime decoder/Fresnel path. GPU readbacks verify actual remapped preset F0 is albedo-independent and actual angular/reflection response follows the source equations; enhanced standard-aligned decoding remains separate.

## Actual volumetric clouds

Visible clouds integrate three-dimensional procedural density over a 192–252 m slab, following the supplied non-Iris fallback height 192 and thickness 5 × scale 12. View integration uses 32 density samples at quarter width/height, Beer–Lambert extinction, four solar shadow samples at each occupied step, forward scattering and bounded ambient scattering. RGB stores premultiplied scattered radiance and alpha stores transmittance. A smooth finite-volume horizon fade avoids a hard cutoff at the ray budget. The full-resolution sky reconstructs that radiance/transmittance and applies it to the sky, sun, moon and stars when the scene integrator is unavailable. With ready primary scene transport, the sky draws clear sky/celestial radiance and the cloud raster integration is skipped: the scene integrator supplies the primary camera-path cloud medium once, avoiding duplicate extinction/scattering. The small cloud target still clears for the GPU frame timestamp anchor.

Shared binding-free `bg_sky_environment` integrates eight view/two solar samples for offscreen rays. `bg_cloud_transmittance` provides eight-sample direct-light extinction to the scene integrator. Sky and cloud sampling use the same world-space density and wind drift. Rain strength is a dedicated precipitation input independent of cloud coverage; a dry overcast sky no longer receives the rain palette. Moon phase follows authoritative server world time, one of eight phases per complete world day; the exact BSL multiplier table drives sky and cloud ambient night radiance. Inputs are unattenuated solar radiance; local cloud extinction supplies the shadow rather than a second global weather multiplier. Downward environment rays have no synthetic ground illumination, and zero radiance inputs produce no invented cloud light.

Fire and rain billboards drawn after scene transport now fade their contrast by the same height-dependent air extinction and actual three-dimensional cloud density along the camera-to-particle segment. Cloud-free air uses the analytic integral; cloud segments use the primary medium’s 16/32/16 sample partition. Original emissive RGB is preserved and coverage is multiplied by transmittance, with no second extinction pass over the resolved scene. This is a billboard visibility approximation, not exact absorbing-sheet transport: it does not reconstruct front-segment in-scattering or compute per-particle multiple scattering. When scene transport is unavailable, existing particle blending stays unchanged.

This density is a **new true 3D volume**, not exact BSL cloud-density parity. BSL's supplied `clouds.glsl` builds its volume from `tex/noise.png` and vertically sliced/detail noise with different density and lighting equations. Quarter-resolution reconstruction and bounded sampling can soften fine cloud detail; environment rays use fewer samples than the visible sky. A high-altitude camera can enter the cloud slab.

## Local source-default cloud comparison

Optional reference modes now have a separate, source-audited `CLOUDS=2` sky pass. `src/render/sky/reference_clouds.wgsl` independently expresses the supplied default density and lighting equations: linear repeated R-channel base noise, vertically interpolated B-channel detail slices, coverage/amount/density controls, rain response, source frame-time wind, sun reveal, source active sun/moon direction and shadow fade, the bounded 32-sample slab calculation, distance fade, gradient lighting, source palettes and squared opacity. The supplied non-Iris fallback is 192–252 m; `CLOUD_HEIGHT=-1` also retains its source 10/73 distance normalization. Submitted camera sample indices explicitly drive the default TAA cloud dither; static preview helpers default to sample zero. The optional reference pass renders at full camera resolution to preserve the source pixel dither lattice; enhanced cloud integration stays at quarter width/height. The engine temporal shader currently rejects depth-1 sky pixels, so it does not accumulate this source cloud dither even in live play. Clear/sunset reference captures retain visible grain; source sky/cloud TAA remains a reference integration gap. The sky-depth case `z=1` is implemented; BSL's foreground-depth cloud masking, cloud reflection calls and their shortened distance fade are not reconstructed by this pass. Biome fog weights and Iris-provided cloud height remain unavailable. The source enables biome weather, but all default cold/dry/damp fog-density multipliers are 1, so the default cloud fog density is 1.

The original BSL noise PNG is **not bundled or committed**. The supplied shader directory has no license file; the author's [official project terms](https://www.curseforge.com/minecraft/shaders/bsl-shaders) and [license](https://www.curseforge.com/minecraft/shaders/bsl-shaders/license) state All Rights Reserved, allow personal modification, and require permission for redistribution. This is local comparison work against user-supplied inputs, not a redistributable BSL shaderpack. In a reference mode, `BLOXGLOOM_BSL_NOISE=/absolute/path/to/noise.png` selects the local 512×512 RGBA image; absent that variable, `external/shaders/tex/noise.png` is the local default lookup. Missing/invalid input explicitly reports reference clouds unavailable and uses enhanced clouds. The audited supplied input has SHA-256 `5ff93225ed7018e90822824a599e4e080e985fb882fdc15ac9e117dd8ba22a34`, is sampled as linear RGBA8 with repeat/linear filtering, and is not an sRGB artwork texture.

Enhanced true 3D cloud density, direct cloud shadows and path-traced cloud transport remain separate. GPU known-input fixtures use independently constructed constant noise and double-precision density, Bayer dither, opacity and clear/rain/night volume-lighting oracles, with no original BSL asset test dependency. Those fixtures verify the implemented helpers; they do not verify a matched Minecraft/Iris frame.

## Runtime inputs and effects still required for whole-frame parity

- A captured BSL/Minecraft/Iris frame with the same scene, camera, time, weather, exposure and actual runtime settings.
- Exact Minecraft/Iris celestial transforms, per-vertex colors and texture-compositing convention. The provided JG RTX Java sun and eight-phase moon textures are now imported unchanged, sampled from a world-oriented celestial quad, and attenuated by the actual cloud volume. The atlas index follows authoritative world day modulo eight. The shader uses explicit quad half-extents 0.30/0.20, hardware sRGB texture decoding, additive radiance and calibrated engine solar gain; these runtime transforms/color conventions still require matched BSL frame verification.
- Celestial source equations are now implemented in the optional reference modes: the custom `timeAngle` warp from `shaders.properties`, the cosine-softened orbit from `gbuffers_terrain.glsl`, source `shadowFade` and active sun/moon selection. Enhanced rendering retains the calibrated `SUN_DIRECTION` orbit. The engine's authoritative normalized world-day phase is mapped directly to the reference `sunAngle` input. A particular Minecraft/Iris version's runtime tick interpolation and `getTimeOfDay`/environment-attribute transform are not supplied, so clock-to-frame equivalence remains unverified.
- Biome weather weights and Iris cloud height/bedrock level. The sky port uses the default rain palette/fog density and the non-Iris cloud-height fallback. Engine world time supplies lunar phase and equivalent time brightness; coordinate conventions differ from Minecraft. Dedicated precipitation strength drives rain styling; cloud coverage independently drives cloud density. Actual JG RTX eight-phase moon artwork supplies the phase atlas.
- Whole-frame BSL cloud/depth/reflection integration, bloom pyramid, shadow filtering, water and remaining post effects. The local source-default sky-cloud comparison is described above; enhanced clouds remain a different density and transport model. Reference normal-air distance/density/height/exterior equations and the default `GetFogColor` HDR palette are implemented. Engine smoothed roof exposure is an explicit proxy for Minecraft `eyeBrightnessSmooth.y/240`, not an equivalent runtime light measurement. Engine bedrock −64 is supplied to the source Iris bedrock equation; other Minecraft version/dimension branches are not mapped. Authoritative eye-medium classification and source final-composite underwater absorption, lava/powder-snow fog, blindness/darkness, and night vision are not implemented by this air-fog helper. Applying water absorption per raster surface would misrepresent the source composite stage, so it is not inferred from shelter. Default-reference lightmap and smooth-lighting inputs come from engine voxel lighting/baked AO; botanical classification comes from catalog metadata; catalog emission substitutes for Minecraft block-ID mappings; LOD/basic actor lighting uses a simplified source-light branch rather than the complete near-material lightmap/desaturation path; actor/local colored light and hardware sRGB texture decoding differ from the source runtime. Current GI, material relief, scene reflections, atmosphere and cloud transport are enhanced engine systems, not default BSL implementations.

Reference source equations and enhanced rendering are deliberately identified separately. Matching a few equations or producing a similar image does not prove whole-frame parity.
